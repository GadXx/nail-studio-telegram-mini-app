# Участие в проекте

Спасибо за помощь в развитии Nail Studio. Держи изменения небольшими и связанными с конкретной проблемой пользователя или эксплуатации. Обновляй документацию при изменении поведения или настроек.

## Локальная настройка

1. Установи Node.js версии 20 или новее.
2. Выполни `npm ci`.
3. Скопируй `.env.example` в `.env` и задай случайный `SESSION_SECRET`.
4. Скопируй `data/salon.example.json` в `data/salon.json` и замени тестовый Telegram ID до запуска приложения.

## Перед созданием pull request

```sh
npm run check
```

Проверка анализирует синтаксис JavaScript. Для изменений Mini App в Telegram WebView, правил записи, миграций базы или настроек сервера опиши ручную проверку. Не добавляй в коммиты `.env`, персональную конфигурацию салона, базы, данные клиентов и загруженные фотографии.

## Pull request

- Опиши проблему и пользовательские изменения.
- Отметь изменения базы и инструкции для развёртывания.
- По возможности приложи скриншоты интерфейсных изменений.
- Не включай секреты и реальные данные клиентов в коммиты, журналы, скриншоты и обращения.
